# 2026-08-05 — 절차 맵 생성 게임플레이 루프 통합(알고리즘 개편 + 런타임 어댑터)

## 요약

복도가 막다른 끝에 남고 직결/경유 혼합을 제어할 수 없다는 문제로 시작해, 레이아웃 알고리즘을 "복도+끝방 원자 배치" 체계로 개편했다(예산도 방 전용 집계로 전환, 상한 60). 다각 검증 워크플로가 구버전 전제의 PipelineTests 공허성 가드가 결정적으로 실패하게 된 것과 GeneratorVersion 미인상 2건을 확정 결함으로 잡아내 함께 수정했다. 이어 "진공 상태 조율보다 실제 게임 루프 투입"으로 방향을 틀어 오케스트레이터 스켈레톤 10개(어댑터 5·문 3·해시·인터랙터)를 전부 필인 — 시드 복제→로컬 조립→해시 대조→NavMesh 서버 베이크→상태 오브젝트 스폰 파이프라인을 완성했다. 서버가 손의 열쇠를 재검증하라는 스켈레톤 요구는 PlayerInventory 가 비네트워크라 불가능해, 클라 이중 가드 + 승인 후 대상 클라 소멸로 낮춰 구현하고 편차를 보고했다. unity-cli 커넥터가 세션 내내 무응답이라 dotnet 독립 컴파일 하니스(실제 Unity/Netcode DLL 참조)로 검증을 대신했고, 이후 에디터가 자체 복구되어 Editor.log 기준 컴파일 클린을 확인했다. 마지막으로 스폰 체계를 실물 프리팹 사정에 맞춰 보강(좀비 원점/반경 주입, 열쇠 변종, 무리 배회 OFF, Oil→Fuel)했다. 문 프리팹 제작·등재가 마지막 남은 퍼즐이다.

## 레이아웃 알고리즘 개편 (60e6483)

- 복도를 "복도+끝방 원자 트랜잭션"으로만 배치(실패 시 롤백) — 막다른 복도 구조적 차단, `CorridorLinkPercent`(기본 50%)로 직결/경유 혼합 제어. `LayoutGenerator.cs` 전면 재구성
- 총 방 수 예산을 방 전용 집계(복도·입구 제외)로 전환, 사용자 지시로 기본 상한 60(`RoomsTotalMax`) — 방 3종 MaxCount 합 66으로 보충
- 복도 포함 간선은 전부 개방 통로(문·자물쇠 금지) — `AddEdge` 통합 + `LockKeyPlacer` 후보 제외 `&&`→`||`
- 검증 워크플로 확정 결함 수정: PipelineTests 복도쌍 테스트 재작성(구 규칙 전제 공허성 가드), GeneratorVersion 0.1.0→0.2.0, X4 가드 2건(복도 MinCount 모순·3변 복도 차단)
- 독립 하니스 실측(워크플로): 시드 2,100개 구성 전수에서 막다른 복도 0·결정론 불일치 0·파이프라인 600회 실패 0

## M7+P5/P6 런타임 어댑터 (064bcd7, 5a1b3ad)

- 스켈레톤 10개 필인: `MapGenNetworkDriver`(시드 확정 X8·선검증·복제·해시 집계 X7), `MapRuntimeAssembler`(씬 빌더 이관 — 문 자리는 DoorAnchor), `MapTemplateCatalog`(정의 단일 원천), `BlueprintHash`(FNV-1a), `MapNavMeshRuntimeBaker`(바닥 전용 서버 베이크), `MapStateObjectSpawner`(문→아이템→좀비), Door 3종(벽장 패턴), `PlayerInteractor` E1/E5 전역 예외
- 편차 보고 3건: 서버 열쇠 재검증 불가(인벤토리 비네트워크 — 완전한 서버 권위는 인벤 복제 선행 필요), `MapTemplateCatalog` 파일 Core 이동(에디터 asmdef 참조 제약), 좀비 배회 반경 주입 API 부재(→ 이후 세션에서 해소)
- 검증 방식: 커넥터 사망으로 dotnet 독립 컴파일 하니스 구축(실제 Unity 모듈/Netcode/Border/Assembly-CSharp DLL 참조) — 소스·DLL 타입 정체성 아티팩트 제외 오류 0
- 원클릭 셋업 툴 `MapGenRuntimeSetup`(Tools/Map/런타임 어댑터 셋업): 채널 2종·레지스트리 생성, MANAGERS 프리팹 MapGenManager 배선, 플레이어 프리팹 참조 연결. 드라이버는 서버 스폰 시 임시 자동 시작
- 로컬라이즈 INT_MSG_LOCKED 시트 등재 완료(테이블 재생성은 에디터 복구 후)

## 스폰 체계 보강 (1818021, ca791a4)

- `ZombieController.ServerConfigureSpawn`: 스폰 시 배회 원점(마커 위치)·반경(WanderRadiusCells×4m) 서버 주입 — ZombieSetting 래퍼 없이 좀비 루트 프리팹 단독 스폰으로 확정
- HerdArea 방 Walker 는 배회 OFF — ZombieCrowd 프리팹은 절차 맵에서 미사용 확정(생성기가 무리 인원을 개별 스폰으로 이미 산출, NGO 중첩 NetworkObject 스폰 불가)
- 자물쇠는 독립 오브젝트가 아니라 문 프리팹의 면(DoorLockFace)으로 확정 — `lockVisualsByPair`(페어 번호별 자물쇠 비주얼 토글) 추가, 열쇠는 레지스트리 `KeyPrefabs` 변종(인덱스+1=번호, 최대 5쌍) + pairId 주입 병행
- `SpawnKind.Oil`→`Fuel`, `ItemCategoryMask.Oil`→`Fuel` 개명(게임 오브젝트 명칭 정합). `OilCount` 파라미터는 스펙 용어라 유지
- 레지스트리 커스텀 인스펙터(사용자 작성)에 Fuel 반영·HerdArea 슬롯 제거·열쇠 변종 섹션 추가
