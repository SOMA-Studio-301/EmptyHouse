# 2026-07-19 — 로비 UI/네트워크 교통정리 리팩토링

## 배경

로비 스크립트(UIMenuManager·UIMenu·UILobby·LobbyManager·RoomManager)의 책임이 얽혀 있어 정리 요청.
요구사항: ① 모든 버튼 UIGenericButton화 ② `Clicked`는 직속 부모 뷰만 구독 ③ 부모(UIMenuManager)가 자식 뷰의 버튼 액션을 배선 ④ UGS/Relay/Netcode 코드가 UI에 얽힌 문제 해소.
착수 시점에 LobbyListCell이 UIGenericButton 전환 도중 멈춰 컴파일이 깨져 있었음.

## 변경 내역 (커밋 순)

1. `b0eb9e7` — 착수 전 미커밋 작업(Menu.unity, MenuPanel.prefab, LobbyListCell.cs) 베이스라인 커밋.
2. `b1db1da` **Phase 0 — 컴파일 복구**: LobbyListCell을 `event Action<Lobby> JoinClicked` + `SetLobbyInfo(Lobby)` 형태로 재작성, UILobby가 셀 이벤트 구독. LobbyEntryUI.prefab의 JoinButton에 UIGenericButton 추가·배선(onClick→Click 퍼시스턴트 콜, SFX 채널).
3. `c3b5118` **Phase 1 — 배선 규약 통일**: `UIGenericButton.Clicked` 포함 모든 공개 `UnityAction` 필드를 `event Action`으로 전환, 부모의 `=` 대입을 `+=`/`-=` 쌍으로 통일. UserPanel의 raw `Button SlotButton` 노출 제거 → UIGenericButton + `InviteClicked` 이벤트 + 빈 슬롯 게이트로 캡슐화, UIRoom의 남의 버튼 onClick 조작 삭제. UserPanel.prefab 배선(Disabled 틴트는 기존 무틴트 유지 위해 NormalColor와 동일화). UISettings의 UnityAction[] 타입 정합 수정.
4. `ee87bc9` **Phase 2 — LobbyDataKeys**: 세 파일에 삼중 복제된 UGS 데이터 키 문자열("Password" 등)을 정적 클래스로 단일화.
5. `4e710af` **Phase 3 — LobbySession 추출(핵심)**: 세션 상태(currentLobby·호스트 판정·isStartingGame·하트비트·생성/입장/퇴장/삭제)를 LobbySession이 단독 소유. LobbyManager/RoomManager는 얇은 프레젠터로 축소, 양방향 [SerializeField] 참조와 `IsInvoking("SendLobbyHeartbeat")` 문자열 크로스콜 제거. 하트비트는 세션 내부 InvokeRepeating(멱등 EnsureHeartbeat, 모든 UpdateLobby write-through에서 재평가 → 방장 승격 안전). OnDestroy에서는 이벤트 미발행 + 문자열만 캡처하는 detached 퇴장.
   - **실버그 2건 수리**: 방 퇴장 후 LobbyManager의 stale currentLobby로 자동 목록 갱신이 영구 정지하던 문제, OnDestroy에서 이미 떠난 로비에 RemovePlayerAsync 이중 발사하던 문제.
6. `5a82245` **Phase 3c — 프리팹**: CanvasController.prefab에 Session 자식 GO 신설, 매니저들의 session 참조 배선.
7. `c2f1739` **Phase 4 — 단일 배선 지점**: UIMenuManager가 uiMenu/uiLobby/uiRoom의 모든 버튼 의도를 매니저 공개 요청 API(RequestCreate/RequestJoin/RequestToggleReady 등)로 라우팅하고, 세션 이벤트 기반 화면 전환(로비↔방)을 전담. 매니저는 데이터 렌더링(목록·경고·슬롯)만 하향 뷰 참조로 수행.
